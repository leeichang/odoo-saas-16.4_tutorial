# 特殊屬性使用說明

## translate 屬性 - 多語言支援

### 🌐 功能說明
`translate=True` 屬性讓欄位支援多語言翻譯功能。

### 🎯 視覺效果
- 欄位右側會出現**翻譯圖示** (🔄)
- 點選圖示可以設定不同語言的翻譯值
- 系統會根據使用者的語言設定顯示對應的翻譯

### 💡 使用場景
- 產品名稱
- 分類名稱  
- 說明文字
- 任何需要多語言支援的文字欄位

### 🔧 程式碼範例
```python
translatable_name = fields.Char(
    string='多語言名稱 (translate)',
    translate=True,
    help='支援多語言翻譯，右側會出現翻譯圖示'
)
```

## tracking 屬性 - 變更追蹤

### 📊 功能說明  
`tracking=True` 屬性讓欄位變更會被記錄到 Chatter（聊天記錄）中。

### 🎯 視覺效果
- 欄位值變更時會在記錄下方的**對話框區域**顯示變更歷史
- 顯示格式：「使用者名稱 將 欄位名稱 從 舊值 改為 新值」
- 包含變更時間和操作者資訊

### 💡 使用場景
- 狀態欄位
- 重要的業務欄位
- 需要審計追蹤的欄位
- 工作流程中的關鍵變更點

### 🔧 程式碼範例
```python
status = fields.Selection([
    ('draft', '草稿'),
    ('done', '完成')
], string='狀態', 
   tracking=True)  # 狀態變更會被追蹤

tracked_field = fields.Char(
    string='追蹤欄位',
    tracking=True,
    help='變更時記錄到聊天記錄'
)
```

## 實際測試方式

### 🧪 測試 translate 屬性
1. 在「多語言名稱」欄位中輸入文字
2. 注意欄位右側的翻譯圖示
3. 點選圖示可以設定其他語言的翻譯
4. (需要系統安裝多語言包才能完整測試)

### 🧪 測試 tracking 屬性  
1. 儲存記錄後，修改「追蹤欄位」的值
2. 再次儲存記錄
3. 滾動到記錄下方的**對話框區域**
4. 查看是否出現變更記錄訊息

### 📋 追蹤記錄範例
```
系統管理員 在 2025-08-25 20:30:00 更新了以下欄位：
• 追蹤欄位: "舊值" → "新值"
• 狀態: "草稿" → "進行中"
```

## 注意事項

### ⚠️ translate 屬性
- 只適用於 `Char` 和 `Text` 欄位類型
- 需要系統啟用多語言功能才能完整發揮效果
- 翻譯資料儲存在 `ir.translation` 表中

### ⚠️ tracking 屬性  
- 需要模型繼承 `mail.thread` 才能使用
- 所有欄位類型都支援 tracking 屬性
- 追蹤記錄儲存在 `mail.message` 表中
- 會增加資料庫儲存空間使用量

### 🎯 最佳實務
- 不要對所有欄位都設定 tracking，只對重要欄位使用
- translate 屬性適合用於面向使用者的顯示文字
- tracking 屬性適合用於業務流程中的關鍵狀態變更

---

這兩個屬性是 Odoo 中非常實用的進階功能，正確使用可以大大提升系統的國際化支援和操作可追蹤性！
