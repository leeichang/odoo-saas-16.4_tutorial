# Wizard 除錯功能改進指南

## 問題分析

使用者回報姓名過濾功能產生空白報表的問題，經分析後發現可能的原因：

1. **資料庫中沒有資料**：這是最常見的原因
2. **篩選條件不匹配**：輸入的姓名關鍵字找不到對應記錄
3. **用戶不了解模糊搜尋**：不知道可以輸入部分姓名進行搜尋

## 🔧 解決方案

### 1. **智能除錯系統**
新增 `_debug_filter_conditions()` 方法：
- 顯示資料庫中現有的所有姓名
- 記錄篩選條件到 Odoo 日誌
- 提供詳細的除錯資訊

### 2. **友善錯誤訊息**
改善錯誤提示，包含：
- 當前篩選條件說明
- 資料庫現有姓名列表（前10筆）
- 使用提示和範例

### 3. **自動測試資料建立**
新增 `action_create_test_data()` 功能：
- 當資料庫沒有資料時顯示警告
- 提供一鍵建立測試資料功能
- 建立5筆範例資料供測試使用

## 📊 新增功能特色

### 🚨 **智能警告系統**
```xml

    <p>目前資料庫中沒有資料，無法產生報表。</p>
    <button name="action_create_test_data" string="建立測試資料"/>

```

### 🔍 **詳細錯誤訊息**
```python
error_msg = _('沒有找到符合條件的記錄，請調整篩選條件。\n\n'
             '當前篩選條件：%s\n\n'
             '資料庫現有的姓名：%s\n\n'
             '提示：姓名過濾支援部分符合，例如輸入「張」可以找到「張三」')
```

### 📝 **日誌除錯**
```python
_logger.info(f"=== 報表篩選除錯資訊 ===")
_logger.info(f"資料庫中的所有姓名: {record_names}")
_logger.info(f"篩選條件: {filter_description}")
_logger.info(f"Domain: {domain}")
```

## 🎯 使用者體驗改善

### **場景 1：資料庫為空**
- **之前**：產生空白PDF，用戶不知道原因
- **現在**：顯示警告訊息，提供建立測試資料按鈕

### **場景 2：篩選條件不匹配**
- **之前**：只顯示「找不到記錄」
- **現在**：顯示現有姓名列表，提供搜尋提示

### **場景 3：不了解模糊搜尋**
- **之前**：用戶不知道可以輸入部分姓名
- **現在**：錯誤訊息包含使用範例和提示

## 🔄 改進流程

### 1. **預防性檢查**
- 開啟 wizard 時自動檢查資料數量
- 如果沒有資料，顯示建議動作

### 2. **即時回饋**
- `record_count` 欄位即時顯示符合條件的記錄數
- 篩選條件改變時自動更新計數

### 3. **操作指引**
- 提供清楚的使用說明和範例
- 錯誤訊息包含解決建議

## 📈 技術改進

### **新增方法**
1. `_debug_filter_conditions()` - 除錯資訊收集
2. `action_create_test_data()` - 測試資料建立
3. 改良 `action_generate_report()` - 增強錯誤處理
4. 改良 `action_preview_data()` - 增強錯誤處理

### **視圖改進**
1. 條件式警告區塊顯示
2. 測試資料建立按鈕
3. 更清楚的使用說明

## 💡 使用建議

### **給使用者的提示**
1. **姓名篩選技巧**：
   - 輸入完整姓名：「張三」
   - 輸入部分姓名：「張」（會找到所有包含「張」的記錄）
   - 支援中英文搜尋

2. **日期篩選技巧**：
   - 可以只設定開始日期或結束日期
   - 支援任何有效的日期格式
   - 根據記錄的「開始日期」欄位進行篩選

3. **組合篩選**：
   - 選擇「依姓名和日期篩選」可同時使用兩種條件
   - 系統會找出同時符合姓名和日期條件的記錄

### **除錯步驟**
1. 先點選「預覽資料」確認篩選結果
2. 如果沒有資料，檢查錯誤訊息中的建議
3. 調整篩選條件後重試
4. 必要時可建立測試資料進行測試

這些改進讓 wizard 更加使用者友善，能夠主動協助使用者解決問題！ 🎉
